# F6-3：dva 适配

日期：2026-10-25。本切片新增 `@cormijs/dva`：应用显式导入 dva model 并创建 runtime Provider，获得 `useDispatch`/`useSelector`/`useStore`/`useDvaApp`/`connect`。不自动发现 `src/models`，也不引入 Umi 的 dva 插件配置。

## 1. 使用方式

```ts
// src/models/counter.ts
export default {
  namespace: 'counter',
  state: { count: 0 },
  reducers: { increment(state: { count: number }) { return { ...state, count: state.count + 1 }; } },
};
```

```tsx
// src/dva.tsx
import { createDvaRuntime } from '@cormijs/dva';
import counter from './models/counter';
export default createDvaRuntime([counter]);
```

```ts
// cormi.config.ts
app: {
  runtime: [{ id: 'dva', module: { specifier: './src/dva.tsx', exportName: 'default' } }],
}
```

```tsx
import { useDispatch, useSelector } from '@cormijs/dva';
const count = useSelector((state: any) => state.counter.count);
const dispatch = useDispatch();
```

## 2. 契约与语义

- `createDvaRuntime(models, options?)` 校验非空 model 列表、唯一 namespace、reducers/effects/subscriptions 为函数映射；返回 runtime 贡献所需的 `{ Provider }`。
- Provider 每次应用挂载创建一个 dva-core app，注册模型并 `start()`；store 通过 React context 提供给 hooks。
- `useSelector(selector)` 使用 `useSyncExternalStore` 订阅 redux store；selector 应返回稳定值（避免每次新对象导致重复渲染）。
- `useDispatch` 返回绑定 store 的 dispatch；`useStore` 暴露 `{dispatch,getState,subscribe}`；`useDvaApp` 返回 dva app；`connect` 提供 hooks 版 HOC。
- 依赖 `dva-core@2.0.4`、`redux@4.2.1`；不使用 react-redux，避免其 React 19 peer 约束。
- 没有 Cordis 插件/模型扫描/生成文件；应用自己 import 模型并在 runtime 模块组合，模型代码仍是普通客户端源文件。

## 3. 边界

- 不提供 `src/models` 自动发现、`extraModels`、immer/loading 插件、`getDvaApp` 全局单例或 Umi 的 `dva` 配置 schema。
- 只验证 reducer；effects/saga/subscriptions 会注册但未在本切片验证，复杂 effect 行为需应用自行确认。
- 无 SSR dehydration/hydration；Provider 在挂载时创建 store，SSR 应用需自行处理。
- dva-core 没有显式 stop API；Provider 卸载后 React 订阅清理，但 saga task 生命周期未单独验证。
- 不桥接 cormi `modelPlugin`/`useModel`；两套模型系统不要同时管理同一 namespace。
