# U16-2：locale 方向（RTL）

日期：2026-10-22。本切片为 UI locale 适配补充文字方向：`localeDirection` 按语言检测 RTL，支持归一化覆盖；`useLocaleResource` 返回 `direction`，应用可直接传给 Antd `ConfigProvider` 或设置根节点 `dir`。不内置 RTL 样式表。

## 1. 使用方式

```tsx
const ui = useLocaleResource(antdLocales);
return <ConfigProvider locale={ui.resource} direction={ui.direction}>{children}</ConfigProvider>;
```

```ts
import { localeDirection } from '@cormijs/runtime';

localeDirection('ar-EG');                          // 'rtl'
localeDirection('en-US');                          // 'ltr'
localeDirection('en-US', { 'en-US': 'rtl' });      // 'rtl'
```

## 2. 契约与语义

- **检测**：基于归一化后的语言子标签；RTL 集合为 ar/arc/ckb/dv/fa/he/khw/ks/ku/ps/sd/ur/yi；其余默认 ltr。`zh-Hant-TW`、`ja-JP`、`es-419` 等为 ltr。
- **覆盖**：第二参数是资源键到 `'ltr' | 'rtl'` 的映射；键经 `normalizeLocaleTag` 处理（`en_US` 与 `en-US` 等价），按 `localeCandidates` 顺序匹配，先命中的覆盖生效。未命中时回退语言集合判断。
- **Hook**：`useLocaleResource` 结果包含 `direction`，随 locale 重新计算；不读取 `document.dir`，不修改 DOM,由应用显式消费。
- **校验**：覆盖值非法或覆盖表不是对象时抛 `LOCALE_DIRECTION_INVALID`；非法 locale 标签按 ltr 处理。
- **SSR**：`localeDirection` 是纯函数；`useLocaleResource` 在服务端取当前 Provider locale（无 Provider 时 fallback），不做请求头协商。

## 3. 边界

- 不做 RTL 样式翻转、逻辑属性迁移、字体/镜像图标或 Antd 组件封装。
- 不检测 `dir` 属性、浏览器 UI 语言或 `Accept-Language`。
- 覆盖只支持 ltr/rtl 两值，不支持 `auto`。
- 语言集合为静态表，不读取 CLDR 数据。
- 未在真实 RTL 页面做布局截图验证。

## 4. 与 Umi/Antd 的差异

| 方面 | Umi/Antd | cormi U16-2 |
| --- | --- | --- |
| 方向来源 | ConfigProvider direction | `localeDirection`/`useLocaleResource.direction` |
| 自动检测 | 应用/插件 | 语言表 + 覆盖 |
| RTL 样式 | Antd 内置 | 未提供 |
| SSR | 应用处理 | 纯函数 |
