# U17-1：可选 Antd 集成包

日期：2026-10-22。本切片新增可选包 `@cormijs/plugin-antd`：通过 Cordis runtime 贡献把 Antd `ConfigProvider` 接入 cormi，复用 U16 的 locale/回退链/方向判断，并支持受校验的主题 token 与暗色算法。不包含 ProLayout、图标、图表或 Antd 组件封装。

## 1. 使用方式

```ts
import preset from '@cormijs/preset-react-vite';
import { appRuntimePlugin, localePlugin } from '@cormijs/plugin-react';
import { antdPlugin } from '@cormijs/plugin-antd';

export default defineConfig({
  presets: [preset],
  plugins: [
    { id: 'app', plugin: appRuntimePlugin },
    { id: 'locale', plugin: localePlugin, options: { id: 'application:locale' } },
    { id: 'antd', plugin: antdPlugin, options: {
      id: 'application:antd',
      theme: { token: { colorPrimary: '#1677ff', borderRadius: 6 }, dark: false },
    } },
  ],
});
```

```tsx
import { Button, Empty } from 'antd';

export default function Page() {
  return <><Empty /><Button type="primary">Action</Button></>;
}
```

安装：`pnpm add antd`。Antd 的 locale 文件是 CommonJS，cormi 运行时通过包内子路径 `@cormijs/plugin-antd/runtime` 引入，不进入 Node 配置进程。

## 2. 契约与语义

- **组合**：`antdPlugin`（`cormi:antd`，`inject: ['react']`）把 runtime 贡献 `{module: '@cormijs/plugin-antd/runtime', exportName: 'antdRuntime'}` 注册到 `ctx.react.runtime`，stage 20，因此位于 locale Provider 之内；localePlugin 必须先挂载（配置顺序或 stage 顺序），否则 Antd 拿不到当前语言。
- **locale**：Provider 用 `useLocaleResource` 在包内小表中解析官方 Antd locale：ar_EG/de_DE/en_US/es_ES/fr_FR/ja_JP/ko_KR/pt_BR/ru_RU/zh_CN/zh_TW，并提供语言级别名（`en`、`zh`、`ja` 等）与 `zh-Hant`。回退/归一化由 U16 提供；应用不需要传入 locale 对象。
- **方向**：`direction` 来自 `useLocaleResource`（U16-2），ar/he/fa/ur 等 RTL 语言自动传给 ConfigProvider；不注入 RTL 样式。
- **主题**：`theme.token` 最多 128 项，键为字母开头的 1–64 位标识符，值为字符串（≤512）或有限数字；`dark: true` 使用 `antdTheme.darkAlgorithm`。选项由插件校验并序列化为 runtime 贡献，非法值以 `ANTD_INVALID` 失败。
- **卸载**：插件通过 `ctx.effect` 注册/撤回 runtime 贡献；应用卸载时 Antd Provider 随 React 树销毁。
- **类型边界**：插件入口（Node）不导入 antd；只有 runtime 子路径导入 antd，未安装 antd 的纯服务端消费者不会因 optional peer 失败。

## 3. 边界

- 本切片不提供 ProLayout 外壳、Antd Menu/Form/Table 封装、图标、图表或主题编辑器；ProLayout 见 [U17-2](134-u17-pro-layout.md)，菜单项仍可用 U17 的 `toAntdMenuItems` 适配器。
- 只内置 11 个 Antd locale 模块；其他语言需要扩展包，不能通过选项传入自定义 locale 对象。
- Antd 6.6.7 部分 `@rc-component/*` 声明在 `skipLibCheck: false` 下会报错；应用需开启 `skipLibCheck`（本切片 fixture 如此）。这属于上游类型问题，不是 cormi 运行时限制。
- 未验证 RTL 页面截图、Antd SSR 样式抽取或 CSS-in-JS 首屏样式；SSR 渲染 Antd 组件仍依赖现有 runtime。
- 主题 token 只做 JSON 浅校验，不校验 Antd token 名称或类型语义。
- `antd`/`dayjs` 作为根开发依赖安装，用于真实浏览器与安装包消费验证。

## 4. 与 Umi 的差异

| 方面 | Umi 4 + Antd | cormi U17-1 |
| --- | --- | --- |
| 接入方式 | 内置插件/配置 | 可选包 + 原生插件 |
| locale | antd 插件映射 | 包内小表 + U16 回退链 |
| 方向 | ConfigProvider direction | 自动 RTL 检测 |
| 主题 | antd 配置 | JSON token/dark |
| ProLayout/图表 | 生态 | 未提供 |
