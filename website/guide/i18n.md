# 国际化

cormi 的 locale 层提供运行时语言切换、消息目录、ICU 子集、数字/日期/相对时间格式化，以及 UI 库语言资源解析。它不内置 Antd/dayjs 或它们的语言包。

## 启用

同时启用 app 运行时与 `localePlugin`：

```ts
import { appRuntimePlugin, localePlugin } from '@cormijs/plugin-react'

plugins: [
  { id: 'app-runtime', plugin: appRuntimePlugin },
  { id: 'locale', plugin: localePlugin, options: { id: 'application:locale' } },
]
```

```tsx
// src/app.tsx
export default defineApp({
  locale: {
    default: 'zh',
    fallback: 'en',
    storageKey: 'app:locale',
    messages: {
      en: { title: 'Console', greeting: 'Hello, {name}' },
      zh: { title: '控制台', greeting: '你好，{name}' },
    },
  },
})
```

| 配置 | 说明 |
| --- | --- |
| `default` | 初始语言；未设置时使用应用默认值 |
| `fallback` | 当前语言缺少 key 时的回退语言 |
| `messages` | 内联消息表，`locale → key → text` |
| `storageKey` | 切换后尽力持久化到 `localStorage` |

语言切换不会刷新页面；`LocaleProvider` 会重新渲染读取 `useIntl` 的组件。

## 消息目录

文案较多时，把消息放进 `src/locales/<locale>.json`：

```json
{
  "title": "控制台",
  "menu.admin": "管理后台",
  "greeting": "你好，{name}"
}
```

```ts
plugins: [{
  id: 'locale',
  plugin: localePlugin,
  options: { id: 'application:locale', directory: 'src/locales' },
}]
```

目录在 Node 侧读取，并以内联 JSON 写进生成入口，**浏览器不会再发额外请求**。

- 文件名必须是合法 locale，例如 `zh-CN.json`、`en.json`。
- 文件必须是扁平的 `key → string` 表，最多 512 个 key。
- 同一 locale 的重复 key 会直接失败。
- `src/app.tsx` 的 `locale.messages` 会按 key 覆盖目录值。

## useIntl

```tsx
import { FormattedMessage, useIntl } from '@cormijs/runtime'

function Header() {
  const { locale, setLocale, t } = useIntl()

  return (
    <>
      <button onClick={() => setLocale(locale === 'zh' ? 'en' : 'zh')}>
        {locale}
      </button>
      <h1>{t('title')}</h1>
      <p>{t('greeting', { name: 'Ada' })}</p>
      <FormattedMessage id="greeting" values={{ name: 'Grace' }} />
    </>
  )
}
```

`IntlApi`：

| 成员 | 说明 |
| --- | --- |
| `locale` | 当前语言 |
| `setLocale(locale)` | 切换语言 |
| `subscribe(listener)` | 订阅成功切换，返回取消函数 |
| `t(key, values?)` | 查表并插值；未命中时回退，最终以 key 作文本 |
| `peek(key)` | 只查表，不把 key 当作文本返回 |
| `formatNumber(value, options?)` | 当前语言的数字格式 |
| `formatDate(value, options?)` | 当前语言的日期格式 |
| `formatRelativeTime(value, unit, options?)` | 相对时间 |
| `tp(key, count, values?)` | 复数消息 |
| `rich(key, values, tags)` | 富文本消息，返回 ReactNode |

`FormattedMessage` 支持 `id`、`values`、`defaultMessage` 和 `tags`。

## 数字、日期与相对时间

```tsx
const { formatNumber, formatDate, formatRelativeTime } = useIntl()

formatNumber(1234.5)                       // en: 1,234.5；de: 1.234,5
formatDate(Date.now(), { dateStyle: 'medium' })
formatRelativeTime(-2, 'day')              // en: 2 days ago；zh: 2天前
formatRelativeTime(-1, 'day', { numeric: 'auto' }) // en: yesterday
```

非 React 场景使用纯函数：

```ts
import { formatDateFor, formatNumberFor, formatRelativeTimeFor } from '@cormijs/runtime'
```

非法数字/日期、非法相对时间单位会抛 `LOCALE_INVALID`。相对时间只做格式化，不自动刷新，也不读取当前时间。

## 复数

```json
{
  "items_one": "{count} item",
  "items_other": "{count} items"
}
```

```tsx
const { tp } = useIntl()
tp('items', 1)  // items_one
tp('items', 3)  // items_other
```

查找顺序：当前语言的 `${key}_${category}` → `${key}_other` → 当前语言普通 key → fallback 语言同样顺序。复数类别由 `Intl.PluralRules` 决定，`{count}` 自动插值。

## ICU 消息子集

单条消息内需要组合复数、选择和格式化时，直接在消息里写 ICU：

```json
{
  "guests": "{count, plural, offset:1 =0 {no guests} =1 {just you} other {you and # others}}",
  "reply": "{gender, select, female {She replied} male {He replied} other {They replied}}",
  "total": "Total {amount, number} ({fee, number, percent} fee)"
}
```

```tsx
t('guests', { count: 3 })             // you and 2 others
t('reply', { gender: 'female' })      // She replied
t('total', { amount: 1234.5, fee: 0.25 })
```

支持：

- 简单参数 `{name}`
- `{n, number|date|time[, style]}`，包括 `integer`、`percent`、`short`、`medium`、`long`、`full`
- `plural`、`selectordinal`、`select`，可嵌套、可带 `offset:N`
- `#` 计数占位和单引号字面量
- `=N` 始终匹配原始值；`offset` 只影响复数类别与 `#`

**没有传值时 `t` 不解析消息，原样返回目录文本**；传值后语法错误会抛 `LOCALE_INVALID`。纯函数 `formatIcu(message, values, locale)` 也可单独使用。

货币、骨架格式和编译期消息校验不在当前子集内。

## 富文本

```json
{
  "notice": "<b>Hello {name}</b>, you have {count, plural, one {# message} other {# messages}}"
}
```

```tsx
const { rich } = useIntl()

rich('notice', { name: 'Ada', count: 2 }, {
  b: children => <strong>{children}</strong>,
})

<FormattedMessage
  id="notice"
  values={{ name: 'Ada', count: 2 }}
  tags={{ b: children => <b>{children}</b> }}
/>
```

`t()` / `tp()` 不解析标签，按普通文本返回；只有 `rich` / `FormattedMessage.tags` 会解析。标签可嵌套、内部可用 ICU 参数与 `#`；未列出、错配或未闭合标签抛 `LOCALE_INVALID`。cormi 不生成 HTML 字符串，渲染器由应用提供。

## 类型

启用消息目录后，会生成 `.cormi/locale.d.ts`：

```ts
const key: CormiLocale.MessageKey = 'greeting'
const code: CormiLocale.Code = 'zh-CN'

// @ts-expect-error 未知 key
const typo: CormiLocale.MessageKey = 'missing'
```

- 无需 import，`tsconfig` 包含 `.cormi/**/*` 即可。
- 只覆盖目录来源；`app.tsx` 内联消息不参与生成。
- `t()` 的参数仍是 `string`，不会拒绝动态 key。
- 没有目录时类型为 `never`。

## UI 库语言资源

`useLocaleResource` 按 locale 回退链从应用提供的资源表中选择 Antd locale、dayjs 加载函数等：

```tsx
import { ConfigProvider } from 'antd'
import enUS from 'antd/locale/en_US'
import zhCN from 'antd/locale/zh_CN'
import { useLocaleResource } from '@cormijs/runtime'

const antdLocales = { en_US: enUS, zh_CN: zhCN }

function UiLocale({ children }) {
  const { resource, direction } = useLocaleResource(antdLocales)
  return (
    <ConfigProvider locale={resource} direction={direction}>
      {children}
    </ConfigProvider>
  )
}
```

`useLocaleResource` 返回 `{ locale, key?, resource?, direction }`。`zh_CN` 与 `zh-CN` 等价；回退链是完整标签 → 语言-Script → 语言。资源表应在模块级定义，避免每次渲染新建对象。

相关工具：

```ts
import {
  dayjsLocaleCandidates,
  localeCandidates,
  localeDirection,
  normalizeLocaleTag,
  resolveLocaleResource,
} from '@cormijs/runtime'

normalizeLocaleTag('zh_hant_tw')   // zh-Hant-TW
localeCandidates('zh-Hant-TW')     // ['zh-Hant-TW', 'zh-Hant', 'zh']
dayjsLocaleCandidates('zh-CN')     // ['zh-cn', 'zh']
localeDirection('ar-EG')           // 'rtl'
```

RTL 由语言判断，可用 `localeDirection(locale, overrides)` 覆盖。`direction` 可直接传给 `ConfigProvider` 或根节点的 `dir`。

## 订阅语言变化

```tsx
useEffect(() => {
  return intl.subscribe(locale => dayjs.locale(locale))
}, [intl])
```

也可以监听窗口事件：

```ts
window.addEventListener('cormi:localechange', event => {
  const { locale, previous } = (event as CustomEvent).detail
})
```

只在 `setLocale` 成功后通知，初始挂载不回调。框架不会自动修改 dayjs/Antd 的全局语言。

## 限制

- SSR 尚未按请求协商 locale 或注入语言数据。
- 不内置 Antd/dayjs 语言包，也不做 Script→Region 的官方别名映射。
- ICU 子集不包含货币、骨架格式或完整 apostrophe 规则。
- 消息目录最多 512 个 key，单条消息最多 2048 字符。
